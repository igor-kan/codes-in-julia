# Radix-2 Cooley-Tukey Recursive Discrete Fourier Transform (`fft_cooley_tukey_d56`)

> Category: **Harmonic Analysis** | Language: **Julia 1.10+**

## Overview

Computes exact radix-2 Complex{Float64} Discrete Fourier Transforms satisfying Parseval energy conservation over power-of-two arrays.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N log N)` |

## Mathematical & Safety Invariants

- Parseval energy sum(|X|^2) / N matches time-domain sum(|x|^2) within 1e-9.
