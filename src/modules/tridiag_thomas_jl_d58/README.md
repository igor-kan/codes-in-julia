# Thomas Tridiagonal System O(N) Solver (`tridiag_thomas_jl_d58`)

> Category: **Linear Systems** | Language: **Julia 1.10+**

## Overview

Solves diagonally dominant tridiagonal banded linear equations cleanly via Thomas forward sweep and backward substitution.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Reconstructed residual ||A*x - d||_2 drops under 1e-12.
