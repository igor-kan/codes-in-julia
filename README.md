# Scientific Computing & Algorithms in Julia

High-performance numerical algorithms, automatic differentiation, spectral PDE methods, symplectic integrators, and linear algebra routines implemented in pure Julia.

## Core Algorithm Suite

In addition to `scientific_julia/`, the repository now includes Julia
implementations of classic algorithms under `data_structures/`, `graphs/`,
`sorting/`, `strings/`, `dp/`, `geometry/`, `math/`, `searching/`,
`selection/`, and `machine_learning/`.
